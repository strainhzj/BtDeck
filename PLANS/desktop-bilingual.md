## 1. 目标、范围与里程碑

保留现有中文，增加可切换英文，使英语用户能独立完成首次登录、下载器接入和日常管理。保持 Vue 2 Options API；不引入 Composition API、不升级框架、不借机重构现有类组件。产品版本号不因登记本计划改变。

- **M1：核心桌面试用**，23～36 人日。满足登录→首次改密→接入 qBittorrent / Transmission→搜索与管理种子→查询模板→删除及回收站闭环。
- **M2：全部桌面双语**，累计 33～52 人日（包含 M1），覆盖全部现有桌面页面及低频管理功能。
- M1 是否独立对外发布尚未决定；可作为内部验收节点继续到 M2，不构成阻塞。
- 不含移动 `/m/*` 专项英文化、Android 原生界面、README、部署文档、静态 Demo fixtures 英文化、跨设备语言同步、历史日志全文翻译。这些是另行立项范围。
- 共享组件影响移动端时必须验证原有中文流程不退化，但不因此承诺移动端完整英文。窄视口会自动进入移动页面，App WebView 强制移动；不为本任务改动路由策略，对外说明桌面支持边界。

## 3. 架构与内容边界

### 3.1 语言基础

- P1 验证 Vue 2 兼容国际化方案；vue-i18n 8 为候选而非已安装 / 已批准依赖。其官方文档已声明停止维护，选型时核对安全及维护状态并记录结论，不直接安装最新版。参考：https://kazupon.github.io/vue-i18n/ 。
- 建议新增 `frontend/src/i18n/`，按 common/auth/navigation/downloader/torrent/search/tracker/recycleBin/orphanFiles/tasks/settings/notifications/errors 组织 zh-CN、en 目录，实际布局由 P1 固定。
- 键使用语义名，如 `torrent.delete.keepData.confirm`；不用中文原句、行号或任意动态拼键。中英文键集合、插值参数一致，TypeScript 类型完整，不新增 any。
- 模板使用统一 $t，工具 / 路由 / 请求层使用同源翻译入口。字段和校验规则用计算属性或工厂生成，不在模块加载时固定译文。
- 选择顺序：手动偏好→浏览器支持的中英文→默认中文；浏览器语言按顺序匹配，具体 zh-* / en-* 归一化由 P1 测试固定。
- localStorage 持久化，读取失败 / 无效值有安全回退；登录页和导航都显示中文 / English；更新 document.lang、界面标题及 Element UI 内置语言。
- 切换不刷新页面、不丢失表单 / 选择项 / 筛选、不触发业务请求。已打开弹窗、校验、提示的更新或关闭重建策略需明确且不得丢失输入；不遗留危险操作的混合语言确认框。
- 中文最终回退；发布范围内缺译是门禁失败，不能靠回退掩盖。公共按钮可共用键，业务危险操作不用模糊通用文案。

### 3.2 哪些翻译，哪些保留

- 翻译页面、表单、校验、菜单、表格、弹窗、通知壳、空 / 加载状态、图表图例与 tooltip、aria-label、结构化状态、动态批量结果。
- 用户名称 / 模板 / 标签 / 分类 / 文件名 / 路径 / Tracker URL 保留原文。下载器和 Tracker 原始诊断保留，外围提供当前语言的状态和处理建议。
- 注释和开发调试日志不列入文案预算。日志页面字段 / 枚举翻译，历史审计文本、脚本输出和历史自由文本通知不改写。
- 完整句子插值、0/1/多项复数；用户参数按文本转义，不引入 HTML 拼接。
- 集中日期 / 数字格式化；不改变 1024 换算、业务枚举、API 参数、日期筛选边界或任务调度时区。语言与时区独立；先核对无时区时间约定，不统一猜成 UTC。

### 3.3 API 与系统内容

- 保持 `{status,msg,code,data}`、list/total/pageSize 及 202/206/207/认证分支语义。不能为了翻译把 data 数组变对象，不能用中文匹配翻译或决定业务分支。
- 复用已有 reasonCode 模式，对核心错误逐接口定义稳定原因标识和参数，前端统一展示；校验错误按 type/loc 处理。未知错误提供本地化说明 / 下一步，原始详情遵守脱敏；不能暴露内部堆栈、密码、token。
- status=error、code=200 等历史分支列为兼容测试，不顺带全局修改成功 / 失败协议。
- 查询和设置预设补稳定 preset_key（最终字段名在 P0/P4 固定），新增 Schema 走 Alembic。旧记录回填只作用于有明确系统归属且可验证身份的记录；中文旧名称最多作为一次性迁移辅助证据，不能成为运行时翻译索引。
- 歧义记录保留原样并记录待处理；用户同名、复制、改名内容不覆盖。初始化按稳定标识幂等；名称、描述、内置条件组名称翻译，查询条件和执行语义不变。条件 JSON 继续遵循现有 Text 序列化契约。
- 新系统通知使用稳定事件标识和参数，在读取 / 展示时翻译，不按产生任务的用户语言永久保存；历史自由文本保留。涉及通知 Schema 同样走迁移并兼容旧数据。
- 下载器连接继续复用 app.state.store，不新增连接实例。
