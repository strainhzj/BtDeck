## 三、浏览器验收步骤（用户执行；**仅用隔离测试数据/目录**）

> 环境：`npm run serve`（或已部署实例）+ 英文语言 + 现有主题；每个宽度收一张截图（建议 1024/1280/1440/1920）。

1. **V01 视觉宽度扫描**：种子列表（含筛选面板展开/列设置/分页）、详情弹窗、下载器设置弹窗（速度/路径/标签页签）、Tracker 看板与四弹窗、任务页（Cron 编辑器）、审计日志、孤儿文件双页签。检查：长英文不截断关键信息、按钮不重叠、表格不横向溢出、`AdvancedMultiSelect` 触发器不换行破形。
2. **V02 危险确认可访问性**：四级删除（等级 1 与等级 3 各一次，取消即可零副作用）、回收站永久删除、孤儿清理/彻底删除/删除副本确认框。检查：影响对象/数量/不可恢复性齐备、取消可见可达、Tab 可遍历、aria-label 已翻译、浏览器 80%/125% 缩放不遮挡按钮。
3. **A01/A02**：英文无痕登录 → 强制改密 → 回到可用页；退出，错密码/错 2FA/断网各一次，确认提示为英文且恢复入口正确。
4. **D01/D02 + T02/T03**：接 qB 与 TR 各一（隔离实例），测试连接/同步、添加/暂停/恢复/校验、Tracker 汇报各一次；断言业务参数与中文环境一致。
5. **C01 抽查**：375px 宽移动版打开 `/m/torrents`，执行转移 / 修改路径各一次（取消即可），确认中文与既有一致。
6. **R01～R06 实操签认**：逐条对照 `PLANS/bilingual/delete-level-review.md`（R01～R05）与 `PLANS/bilingual/orphan-files-review.md`（R06）表格勾选，可附修改意见（改动后重走 parity + 相关单测）。
