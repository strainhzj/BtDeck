# Bilingual terminology

| 中文 | English | Meaning |
| --- | --- | --- |
| 下载器 | downloader | A client such as qBittorrent or Transmission that performs downloads. |
| 种子 | torrent | A BitTorrent task and its metadata. |
| 做种 | seeding | Continuing to upload after a torrent is complete. |
| Tracker | Tracker | A service that provides peer discovery and reports torrent state. |
| Tracker 异常 | tracker error | A status marker for failed or abnormal Tracker reporting. |
| 查询模板 | query template | Reusable simple-search or advanced-search conditions. |
| 孤儿文件 | orphan file | A file on disk that is not referenced by a torrent in the current downloaders. |
| 隔离区 | quarantine | A pre-deletion holding area for review and recovery. |
| 回收站 | recycle bin | A holding area for recoverable deletion operations. |
| 伴侣模式 | companion mode | Android mode that connects to an already running BtDeck server. |
| 本机服务端模式 | on-device server mode | Android mode that runs BtDeck inside the phone's private directory. |
| 能力矩阵 | capability matrix | The runtime contract that controls visibility and availability by platform and downloader capability. |
| 原因码 | reasonCode | A stable API error identifier localized by the UI. |

Keep the product name `BtDeck` and downloader names `qBittorrent` and `Transmission` unchanged.
