# 双语术语表

| 中文 | English | 说明 |
| --- | --- | --- |
| 下载器 | downloader | qBittorrent 或 Transmission 等实际执行下载的客户端。 |
| 种子 | torrent | BitTorrent 任务及其元数据。 |
| 做种 | seeding | 种子完成后继续上传数据的状态。 |
| Tracker | Tracker | 为种子提供 peer 列表和状态汇报的服务。 |
| Tracker 异常 | tracker error | Tracker 汇报失败或返回异常时的状态标记。 |
| 查询模板 | query template | 可重复使用的简单搜索或高级搜索条件。 |
| 孤儿文件 | orphan file | 磁盘上存在但当前没有被下载器种子引用的文件。 |
| 隔离区 | quarantine | 删除前暂存文件、支持复核和恢复的区域。 |
| 回收站 | recycle bin | 为可恢复删除操作提供的暂存区域。 |
| 伴侣模式 | companion mode | Android 连接已经运行的 BtDeck 服务器的模式。 |
| 本机服务端模式 | on-device server mode | Android 在手机私有目录中直接运行 BtDeck 服务的模式。 |
| 能力矩阵 | capability matrix | 根据平台和下载器能力决定功能可见性与可用性的运行时契约。 |
| 原因码 | reasonCode | API 返回的稳定错误标识；用户界面按语言本地化展示文案。 |

产品名 `BtDeck`、下载器品牌 `qBittorrent` 和 `Transmission` 保持原拼写。
