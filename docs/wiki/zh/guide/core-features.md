# 核心功能

BtDeck 的页面围绕“下载器—种子—文件—任务”组织。不同下载器的能力不完全相同，按钮是否显示以服务端能力检查为准。

## 下载器管理

在“下载器”页面可以添加 qBittorrent 或 Transmission，执行连接测试、同步、设置和能力检查。常用配置包括地址、端口、HTTPS、认证信息、下载路径映射、速度调度和标签。

连接成功后，BtDeck 会缓存下载器客户端并按计划同步种子与 Tracker 状态。下载器暂时离线时，页面会保留必要的状态信息；恢复连接后再同步。

## 种子管理

种子列表支持多下载器、多状态组合筛选、Tracker 异常标记、列宽记忆、批量操作和实时速度。种子详情包含文件、节点和 Tracker 信息，并支持模糊搜索。

添加种子时：

- 新数据应保持“跳过校验”关闭。
- 只有在已有数据完整、明确希望直接做种时才为 qBittorrent 打开跳过校验。
- Transmission 不提供同等的跳过校验参数，界面会按下载器能力处理。

删除操作按等级区分风险；回收站和隔离区用于给可恢复操作留下回退空间。彻底删除前请确认路径、下载器和备份状态。

## 搜索与查询模板

简单搜索和高级搜索都可以保存为查询模板。系统预置模板用于常见筛选；用户模板与系统模板的权限和可编辑范围不同。模板只保存查询条件，不会复制或移动种子文件。

## Tracker 与任务

Tracker 页面提供关键词、测试、重宣告、消息记录和批量操作。定时任务支持同步、扫描和维护类作业；任务页面显示运行状态、结果、超时和取消信息。

## 孤儿文件与回收站

孤儿文件是磁盘上存在、但当前未被下载器种子引用的文件。扫描结果带置信度、状态和忽视名单信息，并支持隔离区和可恢复流程。扫描、删除和彻底清理都可能影响真实文件，执行前应先查看预览和路径。

## 通知、审计与集成

- 通知中心显示版本更新和系统消息。
- 审计日志记录敏感操作、结果和必要的上下文。
- MCP 服务提供受控的能力目录和服务密钥入口，启用前应阅读部署方的安全要求。
- MoviePilot 集成用于整理相关实例和历史关联，协议版本必须与对端匹配。
