# 移动端与 Android

v1.0.6 同时提供移动 Web 和 Android 双模式客户端。移动端页面与桌面页面共享后端能力，但布局、导航和部分操作流程会针对触摸屏调整。

## 移动 Web

手机浏览器访问 BtDeck 后会进入移动界面，支持仪表盘、种子列表与详情、下载器、Tracker 关键词、回收站、审计日志、孤儿文件和设置等页面。当前移动体验包含：

- PWA 安装；
- 标签页滑动、抽屉手势、下拉刷新；
- 种子和通知列表的有限追加加载；
- 移动版高级搜索和底部条件编辑面板。

如果更新后仍显示旧页面，先关闭旧 PWA 窗口并清理站点缓存，再重新打开；不要直接删除后端数据目录。

## Android 伴侣模式

伴侣模式连接已经运行的 BtDeck 服务器。首次使用需要创建服务器 profile，填写服务器 URL、用户名和凭据，然后执行健康检查。应用会通过 WebView 加载服务器自带前端，并可保存加密凭据以恢复会话。

自签名 HTTPS 需要显式记录 SHA-256 证书指纹。应用不会对任意证书无条件放行。

## Android 本机服务端模式

本机服务端模式在手机私有目录内运行 BtDeck 后端和前端，启动后通过本机 profile 访问。服务端使用动态端口，并在启动阶段依次检查目录、迁移、导入、绑定和健康状态。

该模式只支持 64 位 ABI：`arm64-v8a` 和 `x86_64`。32 位设备无法安装或运行本机服务端。

LAN 开关默认关闭。打开后应用会显示明文和局域网暴露风险；公网 HTTP 地址会被拒绝。文件系统、路径映射、孤儿文件、种子备份、种子转移和高风险删除等能力可能在本机服务端模式被能力矩阵禁用，页面状态以运行时能力检查为准。

## 连接失败时

1. 确认服务器 URL 可从手机访问，且没有把 `localhost` 误填成电脑地址。
2. 检查 `/health/live` 和 `/health/ready` 是否可达。
3. 自签 HTTPS 先完成指纹信任，再重试健康检查。
4. 本机服务端模式检查 ABI、服务通知、启动阶段提示和动态端口。
