# Linux PyInstaller 打包的平台增量依赖（release-artifact-equivalence-gate W1/W2 / G2）。
#
# 安装方式（构建脚本两段式，见 deploy/build-linux.sh）：
#   1. pip install --require-hashes -r backend/requirements-lock.txt   # 公共运行依赖，全量哈希校验
#   2. pip install -r deploy/requirements-linux-package.txt            # 本文件（平台增量）
#
# 原因：requirements-lock.txt 内嵌 --hash 行会激活 pip 哈希模式，要求解析闭包内
# 全部依赖带哈希；pyinstaller 及其传递依赖不属于公共运行锁，无法并入。
# 本文件只允许白名单增量（scripts/release/check_dependencies.py 的
# PLATFORM_EXTRAS_WHITELIST），禁止在此复制/覆盖公共依赖版本；
# 结构由 backend/tests/release/test_dependency_lock.py 强制。
#

# 导致 qbittorrent-api ~=2025.5.0 与主清单 ~=2025.2.0 分叉，且混入了运行时
